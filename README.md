# 🔎 IOC Checker

A Python-based SOC automation tool for checking Indicators of
Compromise (IOCs) using VirusTotal and AbuseIPDB APIs.

## Features

- IP address detection
- Domain detection
- SHA256 hash detection
- VirusTotal reputation lookup
- AbuseIPDB reputation lookup
- Malicious detection count
- Suspicious detection count
- Abuse confidence score
- Country information
- ISP information
- Total abuse reports
- Automatic severity calculation
- Timestamped SOC alerts
- JSON alert storage

## Technologies

- Python 3
- Requests
- REST APIs
- JSON
- Regular Expressions
